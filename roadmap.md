# Roadmap
*This roadmap is not a strict plan. Features and versions may change as the project develops.*

### 0.1 — Tool Foundation
Establish the fundamental systems of RPGForge.

- HUD
- Entities
- Basic RPG data structures

### 0.2 — Adventure Places
Introduce the first playable environment and basic RPG gameplay.

- Major AP Functions
  - Combat
  - Exploration
- Sample Adventure Place

### 0.3 — Progression & Persistence
Expand the sample dungeon and introduce persistent progression.

- Entities
  - Player Character Progression
- Adventure Places
  - Functionality Expansion
- Game Saves
- Sample
  - Larger Dungeon
  - Boss Encounter

### 0.4 — Cities
Expand the world beyond dungeons.

- Adventure Places
  - NPCs
  - Shops
  - Rumors
  - More role-playing interactions
- Sample
  - City

### 0.5 — Campaign Expansion
Expand the sample campaign and improve existing tools.

### 0.6 — Character Creation
Introduce deeper character customization and player-created characters.

### 0.7 — World Exploration
Expand exploration beyond cities and dungeons.

- Pointcrawl-style World Exploration
- Points of Interest
- Wilderness Encounters
### 0.8 — Polish
Improve stability, cohesion and usability of existing systems.

### 1.0 — First Stable Release
Release the first stable version of RPGForge with documentation for creating custom campaigns.


RPGForge uses MAJOR.MINOR.PATCH versioning. MAJOR represents major or breaking changes, MINOR represents new features or systems, and PATCH represents small fixes and improvements. Git tags will be used to mark versions, while branches will be used for individual features and fixes.

**Current version:** 0.1.0

**Status:** Early Development

*This roadmap is not a strict plan. Features and versions may change as the project develops.*
